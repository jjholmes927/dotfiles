# Fleet TUI Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build `bin/fleet` — the integrated streams+lanes curses inbox with real end-states, stars, and gate answering — plus the pre-work hardening the final deck review queued.

**Architecture:** One Python 3 stdlib file, split internally into a pure core (data fetch/derive/format — unit-tested) and a curses shell (paint + keys — verified live in scratch tmux sessions). Data comes from `claude agents --json --all`, `~/.claude/fleet-status/` sidecars, `~/.claude/fleet-stars`, and per-lane git calls. Gate answering reuses the verified hidden-tmux-attach recipe.

**Tech Stack:** Python 3 stdlib only (curses, json, subprocess, unittest). bash 3.2 + BSD tools for the shell edits. tmux ≥3.2, Claude Code CLI ≥2.1.238.

## Global Constraints

- Spec: `docs/superpowers/specs/2026-08-21-fleet-tui-design.md` — layout, state table, and keys there are binding.
- Python stdlib ONLY — no pip, no third-party imports.
- ZERO code comments in Python and shell (hard repo rule; shebangs fine).
- State buckets exactly: `WORKING`, `BLOCKED`, `COMPLETE`, `AWAITING`, `STOPPED` (aligned vocabulary — user decision; never rename).
- Sidecar TSV contract: `state<TAB>ISO-8601-UTC<TAB>note`, single line, written by `bin/fleet-status`.
- Live-verification safety rails: every command that could `switch-client` runs under `env -u TMUX`; never touch the `interpret`/`dotfiles` tmux sessions beyond creating/killing hidden or scratch windows; only ever interact with throwaway Claude sessions you dispatched (`--effort low`); `claude rm` them and remove their sidecar/star files when done.
- Commits: imperative mood, no Claude attribution. `claude/settings.json` carries unrelated churn — never stage it.
- tmux base-index is 1 for windows and panes; capture ids with `-P -F '#{pane_id}'`/`#{window_id}`, never hardcode.

```bash
#!/usr/bin/env bash
set -euo pipefail

usage='usage: fleet-status complete|awaiting "<note>" [--session <id>] [--stop]'

session="${CLAUDE_CODE_SESSION_ID:-${CLAUDE_SESSION_ID:-}}" stop=0
positional=()
while [ $# -gt 0 ]; do
  case "$1" in
    --session)   [ $# -ge 2 ] || { echo "$usage" >&2; exit 1; }; session="$2"; shift 2 ;;
    --session=*) session="${1#*=}"; shift ;;
    --stop)      stop=1; shift ;;
    --)          shift; while [ $# -gt 0 ]; do positional+=("$1"); shift; done ;;
    -*)          echo "unknown flag: $1" >&2; echo "$usage" >&2; exit 1 ;;
    *)           positional+=("$1"); shift ;;
  esac
done

if [ "${#positional[@]}" -ne 2 ]; then echo "$usage" >&2; exit 1; fi
state="${positional[0]}"
note="${positional[1]//[$'\t\n\r']/ }"
case "$state" in complete|awaiting) ;; *) echo "bad state: $state" >&2; echo "$usage" >&2; exit 1 ;; esac
if [ -z "$session" ]; then
  echo 'no session id: $CLAUDE_CODE_SESSION_ID unset and no --session given' >&2
  exit 1
fi
case "$session" in */*|.|..) echo "bad session id: $session" >&2; exit 1 ;; esac

dir="$HOME/.claude/fleet-status"
mkdir -p "$dir"
printf '%s\t%s\t%s\n' "$state" "$(date -u +%Y-%m-%dT%H:%M:%SZ)" "$note" > "$dir/$session.tmp"
mv "$dir/$session.tmp" "$dir/$session"
echo "fleet-status: $state recorded for ${session:0:8}"

if [ "$stop" = 1 ]; then
  claude stop "${session:0:8}" >/dev/null 2>&1 || true
  echo "fleet-status: stop requested for ${session:0:8}"
fi
```

### Task 1: `bin/fleet` pure core + unit tests

**Files:**
- Create: `bin/fleet` (mode 755, `#!/usr/bin/env python3`)
- Create: `tests/fleet_test.py`

**Interfaces:**
- Produces (Tasks 2–4 call exactly these):
  - `fetch_sessions(eng_root) -> list[dict]` — runs `claude agents --json --all`, filters `kind=="background"` and `cwd` under `eng_root`.
  - `read_sidecars(dir_path) -> dict[str, tuple[str, str, str]]` — sessionId → (state, iso, note); unparseable files skipped.
  - `derive_bucket(cli_state, sidecar) -> str` — implements the spec's five-bucket table.
  - `parse_pr(note) -> str | None` — first `PR #NNNN` / `#NNNN` reference in the note.
  - `read_stars(path) -> set[str]`, `toggle_star(path, session_id)`.
  - `lane_status(root) -> dict` — `{name, branch, dirty: bool, worktrees: int}` via git subprocess; raises nothing (returns `{"error": True}` variants).
  - `build_model(sessions, sidecars, stars, lanes) -> dict` — `{counts: {...}, lanes: [...], groups: [(bucket, [row, ...])]}` with starred rows first per group, groups in BLOCKED→WORKING→COMPLETE→AWAITING→STOPPED order, empty groups omitted.
  - `format_counts(counts, width) -> str`, `format_lane_strip(lanes, width) -> list[str]`, `format_row(row, width, selected) -> list[str]` (two lines: header + dim context; drops context when width < 80).
  - `transcript_tail(cwd, session_id) -> str` — last assistant text from `~/.claude/projects/<slug>/<sessionId>.jsonl`; slug = cwd with every non-alphanumeric char replaced by `-`.

class Sidecars(unittest.TestCase):
    def test_roundtrip_and_malformed(self):
        with tempfile.TemporaryDirectory() as d:
            p = pathlib.Path(d)
            (p / "abc-123").write_text("complete\t2026-08-21T10:00:00Z\tnote text\n")
            (p / "bad").write_text("only-one-field\n")
            (p / "ignore.tmp").write_text("complete\tt\tn\n")
            out = fleet.read_sidecars(str(p))
        self.assertEqual(out["abc-123"], ("complete", "2026-08-21T10:00:00Z", "note text"))
        self.assertNotIn("bad", out)
        self.assertNotIn("ignore.tmp", out)


class Stars(unittest.TestCase):

class BuildModel(unittest.TestCase):
    def _sessions(self):
        return [
            {"sessionId": "a" * 36, "id": "aaaaaaaa", "name": "mn3/gate", "state": "blocked", "status": "q", "cwd": "/e/mn3/.worktrees/x", "startedAt": 1},
            {"sessionId": "b" * 36, "id": "bbbbbbbb", "name": "mn2/work", "state": "working", "status": "running", "cwd": "/e/mn2/.worktrees/y", "startedAt": 2},
            {"sessionId": "c" * 36, "id": "cccccccc", "name": "done-one", "state": "done", "status": "idle", "cwd": "/e", "startedAt": 3},
        ]

    def test_group_order_and_star_sort(self):
        sidecars = {"c" * 36: ("complete", "t", "PR #9")}
        model = fleet.build_model(self._sessions(), sidecars, {"b" * 36}, [])
        self.assertEqual([g[0] for g in model["groups"]], ["BLOCKED", "WORKING", "COMPLETE"])
        self.assertEqual(model["counts"]["BLOCKED"], 1)

    def test_empty_groups_omitted(self):
        model = fleet.build_model([], {}, set(), [])
        self.assertEqual(model["groups"], [])
